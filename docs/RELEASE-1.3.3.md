# VideoDrop 1.3.3

VideoDrop adds public YouTube video downloads and 192 kbps MP3 conversion to Chrome, along with direct media downloads, unencrypted HLS, static DASH, track merging and live HLS capture.

- **`VideoDrop-Setup-1.3.3.exe`** is the Windows installer. It copies the extension to `%LOCALAPPDATA%\VideoDrop\Full` and opens Chrome. In Chrome, enable **Developer mode**, click **Load unpacked**, and select that folder. The installer is unsigned.
- **`VideoDrop-Full-1.3.3.zip`** is the unpacked extension. Extract it to a permanent folder and select that folder with **Load unpacked**. It contains the same extension as the installer.
- **`SHA256SUMS.txt`** lists the SHA-256 hashes of both downloads.

After installing, reload your video page and open VideoDrop. See the [project README](https://github.com/Teirdalin/VideoDrop#install-in-chrome) for updates, removal and supported formats.
